# Мини-ПК на Windows 10: настройка с нуля

## 1. Автономная работа
1. BIOS/UEFI: **Restore on AC Power Loss → Power On** (компьютер включается сам при подаче питания от таймера-розетки).
2. Автовход: `netplwiz` → снять галочку «Требовать ввод имени пользователя и пароля» → ввести пароль пользователя.
3. Электропитание: никогда не отключать экран и не переводить в спящий режим
   (`powercfg /change standby-timeout-ac 0`, `powercfg /change monitor-timeout-ac 0`).
4. Обновления Windows: отложить на период выставки (Параметры → Обновление → Приостановить), чтобы ПК не перезагружался днём.
5. Отключить уведомления и «Фокусировку внимания»: Параметры → Система → Уведомления → выключить.

## 2. Принтер HP LaserJet 1018
1. Подключить по USB, дождаться установки драйвера (Windows 10 ставит «HP LaserJet 1018» сам; если нет —
   Панель управления → Устройства и принтеры → Добавить принтер → HP → «HP LaserJet 1018»).
2. Убедиться, что имя принтера совпадает с `printer.name` в `config.yaml`.
3. Скачать **портативный** SumatraPDF (файл `SumatraPDF-*-64.exe`, https://www.sumatrapdfreader.org/download-free-pdf-viewer),
   переименовать в `SumatraPDF.exe` и положить в папку `install\`.
4. Пробный лист: `.venv\Scripts\python.exe apophenia.py test-print`.

Замятие: открыть крышку, вынуть лист, закрыть; задание остаётся в очереди Windows и допечатается само.
Кончилась бумага: добавить бумагу, принтер продолжит сам. Служба хранит свою очередь в `queue\`,
пока команда печати не выполнится успешно.

## 3. GigaChat
1. Ключ: личный кабинет developers.sber.ru → проект GigaChat API → «Authorization key» (длинная base64-строка).
   Вписать в `.env` как `GIGACHAT_CREDENTIALS=...`. Для физических лиц scope `GIGACHAT_API_PERS` (по умолчанию).
2. Сертификат НУЦ Минцифры: `install.ps1` скачивает его в `install\russian_trusted_root_ca.cer`.
   Если не скачался — взять с https://www.gosuslugi.ru/crt (формат PEM/.crt) и положить туда же.
   Крайний вариант: `llm.verify_ssl: false` в `config.yaml` (нежелательно).
3. Проверка: `.venv\Scripts\python.exe apophenia.py models` — печатает доступные модели; выбрать в `llm.model`.

## 4. Автозапуск
```
powershell -ExecutionPolicy Bypass -File install\register_task.ps1
```
Две задачи планировщика при входе пользователя: служба (`install\run.bat`; при падении процесса планировщик перезапускает задачу через минуту) и экран
(`install\kiosk.bat`: Edge в режиме киоска на http://127.0.0.1:8765/). Выход из киоска: Ctrl+Alt+Del → Диспетчер задач.

## 5. Экран
Любой монитор или телевизор по HDMI, горизонтальная ориентация. В Параметрах экрана выставить масштаб 100 %.
Страница подстраивается под любое разрешение.

## 6. Ежедневно (персонал галереи)
Ничего включать и выключать не нужно. Проверить бумагу, переложить листы из лотка в архив. Всё как в эскизе.

## 7. Защитник Windows ругается на архив или папку
В репозитории только текст: Python, промпты, шрифты, корпус, два скрипта PowerShell и два bat-файла.
Если Защитник блокирует распаковку или удаляет файл, посмотреть в «Безопасность Windows → Журнал защиты», какой
файл помечен, нажать «Разрешить». Для выставочного компьютера допустимо добавить папку проекта в исключения:
«Защита от вирусов и угроз → Параметры защиты → Исключения → Добавить папку».
