## Процедура
1. Прочитайте текст целиком.
2. Выпишите кандидатов: фрагменты, где есть перенос между областью ума и областью машины/алгоритма/материала (в любую сторону), либо явные теоретические термины.
3. Для каждого кандидата проверьте критерии исключения его класса. Подпадает под исключение — не включайте.
4. Для каждого оставшегося сформулируйте mapping: source (что переносится) и target (на что). Не получается — не включайте.
5. Не дублируйте: один фрагмент — одна запись, один класс (наиболее специфичный). Перекрывающиеся фрагменты объединяйте.

## Требования к цитате (span)
- Копируйте ДОСЛОВНО, символ в символ, из текста. Цитаты проверяются программно; нераспознанные отбрасываются.
- Минимальная единица — словосочетание, в котором видны обе стороны переноса (обычно 3–20 слов). Одно слово не принимается.
- Не перефразируйте, не сокращайте, не соединяйте части из разных мест текста.

## Формат ответа — строго JSON, без преамбулы, без markdown-ограждений
{
  "evidence": [
    {
      "class": "COMP",
      "span": "точная цитата из текста",
      "mapping": {"source": "область-источник: что переносится", "target": "область-цель: на что переносится"},
      "level": "explicit | scientific_metaphor | meta_metaphor",
      "exclusion_checked": true,
      "reasoning": "одно предложение: в чём перенос и почему не подпадает под исключение"
    }
  ],
  "notes": "кратко: что было отброшено по исключениям или почему свидетельств нет"
}
Если свидетельств нет: {"evidence": [], "notes": "..."}.
Допустимые значения class: COMP, IIT, PRED, GWT, ENACT, PAN, EMERG.
