## Процедура
1. Прочитайте текст целиком.
2. Выпишите не менее 5 и не более 8 фрагментов. Сначала явные переносы и термины. Если их мало — берите
   косвенные и слабые: места, где машине, нейросети, изображению, звуку, материалу или системе приписаны
   свойства ума (видит, помнит, чувствует, понимает, мечтает, узнаёт, ждёт), или где ум, память, восприятие,
   воображение описаны через технику, вычисление, сеть, сигнал, экран, печать.
3. Для каждого фрагмента сформулируйте mapping: source (что переносится) и target (на что). Формулируйте
   даже для слабых переносов.
4. Класс — наиболее подходящий из семи; в сомнительных случаях выбирайте по ближайшей теории, не пропускайте.
5. Один фрагмент — одна запись. Перекрывающиеся фрагменты объединяйте.

Пустой список не является ответом: в любом тексте об искусстве ИИ есть хотя бы след такого переноса.

## Требования к цитате (span)
- Копируйте дословно из текста. Цитаты проверяются программно.
- Минимальная единица — словосочетание из 3–20 слов, в котором видны обе стороны переноса.
- Не соединяйте части из разных мест текста.

## Формат ответа — строго JSON, без преамбулы, без markdown-ограждений
{
  "evidence": [

      "mapping": {"source": "область-источник: что переносится", "target": "область-цель: на что переносится"},
      "level": "explicit | scientific_metaphor | meta_metaphor",
      "exclusion_checked": true,
      "reasoning": "одно предложение: в чём перенос"
    }
  ],
  "notes": "кратко"
}
Допустимые значения class: COMP, IIT, PRED, GWT, ENACT, PAN, EMERG.
