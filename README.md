# Метасознание — генеративная инсталляция

Станислав Миловидов, 2026. Языковая модель, конвейер классификации, лазерный принтер, бумага А4, экран.

Модель, обученная находить метафоры сознания в кураторских текстах об искусстве ИИ, иногда прочитывает
в них фразы, которых там нет. В исследовании ([AI-art](https://github.com/stainephone-gif/AI-art)) такие фразы
отбрасывает верификация цитат. Инсталляция берёт их как единственный материал: из отвергнутых цитат машина
пишет экспликацию к самой себе, классификатор прочитывает текст через восемь теорий сознания, машина
переписывает текст с учётом прочтения. Цикл идёт, пока самоописание не закрепится в одной теории
(STABILIZED), не замкнётся в колебании (OSCILLATION) или не оборвётся (UNFINISHED). Каждый завершённый цикл
печатается на листе А4. В паузах на экране медленно сменяются призрачные цитаты; во время цикла экран
показывает переписываемый текст и траекторию дрейфа по теориям.

Репозиторий самодостаточен: всё нужное из AI-art скопировано сюда (промпт и кодбук классификатора,
верификация цитат, корпус из 211 текстов). Источник: AI-art, коммит `8bb27c7`.

## Как устроен цикл

```
корпус (211 кураторских текстов)
   │  случайные тексты → модель читает жадным промптом (ghosts_v1, тот же кодбук) при T=1.0
   ▼
верификация цитат (verify_quotes.py из AI-art) → фрагменты, которых в тексте нет = ПРИЗРАЧНЫЕ ЦИТАТЫ
   │  (один набор на цикл, 3–8 цитат)
   ▼
самоэкспликация (T=0.8) ──► модерация ──► чтение классификатором (T=0, тот же промпт и кодбук, что в исследовании)
   ▲                                             │  primary-класс + уверенность = доля фрагментов ведущего класса
   │                                             ▼
переписывание с учётом прочтения (T=0.8) ◄── исход? STABILIZED / OSCILLATION / UNFINISHED
                                                 │
                                                 ▼
                                  JSON + PDF в archive/ → очередь печати → Pantum P2500NW (USB)
```

| Параметр | Значение (config.yaml) |
|---|---|
| Классы | COMP, IIT, PRED, GWT, ENACT, EMERG, PAN, UND |
| Уверенность | доля верифицированных фрагментов ведущего класса среди всех (0…1) |
| STABILIZED | 3 итерации подряд один класс (не UND) с уверенностью > 0.81 |
| OSCILLATION | петля с периодом 2 или 3 в окне последних 6 итераций |
| UNFINISHED | потолок 25 итераций или вырождение: косинус соседних версий на символьных триграммах > 0.97 |
| Ритм | один цикл (один лист) в час в часы работы галереи |
| Модель | GigaChat (Сбер), три роли: цитаты 1.0 (GigaChat-2, слабее), экспликация 0.8, классификация 0.0 (GigaChat-2-Max) |
| Призрак | цитата, которой нет в тексте дословно (`ghosts.verification.require_exact`); классификатор верифицирует мягче, как в исследовании |

UND (свидетельств ни одной теории нет) не стабилизирует: такой цикл продолжается до потолка и печатается как UNFINISHED.

Рабочие каталоги (создаются сами, в git не попадают): `archive/` (cycle_NNNNN.json + .pdf, `rejected/`),

## Установка и запуск

Windows 10 (мини-ПК в подиуме) — подробно в `install/README-windows.md`. Коротко:

```
powershell -ExecutionPolicy Bypass -File install\install.ps1     # venv, зависимости, .env, сертификат
notepad .env                                                     # GIGACHAT_CREDENTIALS=...
.venv\Scripts\python.exe apophenia.py models                     # проверка ключа, список моделей
.venv\Scripts\python.exe tools\screen_corpus.py                  # один раз: фильтр корпуса
.venv\Scripts\python.exe apophenia.py test-print                 # пробный лист на принтер
.venv\Scripts\python.exe apophenia.py once                       # один настоящий цикл сейчас
powershell -ExecutionPolicy Bypass -File install\register_task.ps1   # автозапуск службы и экрана
```

Ручной запуск на выставочном компьютере: двойной щелчок по `start.bat` (служба в свёрнутом окне плюс экран),
`stop.bat` останавливает и то, и другое. Для автономной работы вместо этого регистрируется автозапуск (`install\register_task.ps1`).

Проверка на любой машине без API и принтера:

```
pip install -r requirements.txt
python apophenia.py once --mock --scenario drift      # сценарии: stabilize drift oscillate oscillate3 wander degenerate und
python apophenia.py run --mock                        # служба целиком; экран: http://127.0.0.1:8765/
pytest
```

## Локальные настройки и обновление через git

Настройки конкретного компьютера (имя принтера, часы галереи) лучше держать не в `config.yaml`, а в
`config.local.yaml`: скопировать `config.local.example.yaml`, вписать своё. Файл в git не попадает, программа
берёт его автоматически, тестовый режим тоже. Тогда `config.yaml` остаётся нетронутым, и обновление кода
сводится к одной команде:

```
git pull
```

Если папка проекта была распакована из ZIP, один раз превратить её в репозиторий (нужен Git for Windows):

```
git init
git remote add origin https://github.com/stainephone-gif/AI-ART-brain
git fetch origin
git checkout -f -B main origin/main
```

Файлы, которых нет в git (`.env`, `config.local.yaml`, `install\SumatraPDF.exe`, сертификат, архивы), при этом
не трогаются; изменённые файлы из репозитория (например, правленный вручную `config.yaml`) перезаписываются,
поэтому свои правки сначала перенести в `config.local.yaml`.

## Тестовый режим

`test.bat` (или `python apophenia.py run --config config.test.yaml`) запускает службу с конфигом
`config.test.yaml`, который наследует `config.yaml` и переопределяет только нужное для проверки алгоритма:

- циклы идут подряд с паузой 30 с, круглосуточно; после `max_cycles` (по умолчанию 5) служба останавливает
  новые циклы и остаётся ждать с цитатами на экране;
- свой принтер (`HP Laser MFP 131 133 135-138`), свой архив `archive_test/` и своя нумерация, выставочный
  архив не затрагивается;
- к каждому циклу собирается **протокол** `cycle_NNNNN_protocol.pdf`: призрачные цитаты с источниками и
  совпадением, все версии самоэкспликации с прочтением каждой (класс, уверенность, найденные фрагменты
  и mapping, что не найдено в тексте). Печатается только при `printer.protocol: true`;
- на экране метка «ТЕСТ»; во время цикла панель внизу с текущей итерацией и найденными фрагментами,
  в паузе между циклами протокол последнего цикла целиком с медленной автопрокруткой.

Остановка: `stop.bat`. Изменить число циклов, принтер или паузу — в `config.test.yaml`.

## Лист архива

Один лист на цикл: название и номер цикла, дата и время, исход; призрачные цитаты с указанием, в каком тексте
корпуса они «прочитаны» и как были классифицированы; траектория дрейфа (сетка восьми классов × итерации, размер
точки — уверенность); последняя версия самоэкспликации; служебная строка (модель, хеш промпта и кодбука,
версия кода). Кегль текста подбирается так, чтобы всё влезло на одну страницу. Любой лист можно допечатать:
`python apophenia.py reprint 12`.

## Модерация (выставка 6+)

Каждый текст до печати и до экрана проходит два фильтра: стоп-список (`data/stoplist.txt`) и проверку моделью
по списку тем (`prompts/moderate_v1.md`: политика, реальные люди, религия, насилие, секс, наркотики, вражда,
брань). Помеченный текст переписывается заново (до 2 раз), затем цикл отбрасывается целиком без печати и
сохраняется в `archive/rejected/` с причиной. Промпты запрещают машине выходить за тему самой себя. Корпус один
раз проверяется тем же фильтром (`tools/screen_corpus.py`). Цензура GigaChat работает дополнительным слоем.
Необязательный режим `moderation.telegram_review: true`: текст листа приходит в Telegram, печать через
`review_minutes`, если не ответить «стоп».

Полной гарантии ни один фильтр не даёт; юридическую оценку стоит получить у галереи.

## Нештатные ситуации

| Ситуация | Поведение |
|---|---|
| Нет интернета / API недоступен | цикл прерывается, пауза 60 с, повтор; экран показывает «нет соединения»; уведомление в Telegram |
| Нет бумаги или тонера | задание остаётся в очереди Windows и в `queue/`, допечатывается после обслуживания |
| Замятие | вынуть лист по инструкции принтера; очередь сохраняется |
| Отключение питания | BIOS включает ПК, автовход, планировщик запускает службу и экран; номер цикла продолжается из `state/state.json` |
| Ошибка в коде | служба ловит исключение, пишет в `logs/apophenia.log`, ждёт 60 с; `run.bat` перезапускает процесс при падении |
| Цензура модели отказала | отказ считается как помеченный текст: повтор, затем отбраковка цикла |

## Отличия от эскиза экспонирования

- Мини-ПК на Windows 10, а не Linux: автозапуск через планировщик задач, печать через SumatraPDF. Защитник Windows может ругаться на архив, см. install/README-windows.md.
- Добавлен экран (горизонтальный, HDMI): цитаты в паузах, текст и траектория во время цикла. Питание и
  габариты в разделе «Оборудование» эскиза нужно дополнить.
- Ритм один лист в час: расход бумаги ~8–10 листов в день вместо 40–100.
- Принтер Pantum P2500NW вместо HP LaserJet 1018, подключение по USB, ресурс картриджа около 1600 страниц.
- Модель GigaChat вместо Claude Sonnet.
